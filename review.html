Reviewer instructions

Server URL: https://shynipublic.kihyyo.org
Credentials: provided separately in the store's private review information.
Feedback/support: kihyyo121@gmail.com

The supplied review account is an ordinary non-admin account. It does not require OTP, payment or registration. The server runs the normal Shyni server, not a hidden review-only implementation.

  1. Enter the server URL and sign in with the privately supplied credentials.
  2. Open Open Movies, select Big Buck Bunny, and test play, pause, seek and resume.
  3. Open Scene Studies → Bunny Scene Studies. Play a demonstration excerpt and test the external subtitle track. These are labeled excerpts, not actual TV episodes; subtitles are synthetic test text.
  4. Open Signal Sketches → Shyni Demo → Signal Sketches and play a track.
  5. Open Reading Lab. Test a supported PDF, CBZ, EPUB or TXT reader, navigation, progress and bookmarks.
  6. Open Live TV → Shyni Open Movie Demo to test the looping licensed sample and demonstration program guide.
  7. Sign out. On televisions, test remote focus and Back navigation.

Sample content is original or redistribution-permitted, with attribution at the license link above. Personal cloud accounts, federation peers and DRM services are not configured. Check each submitted client's actual capabilities rather than assuming every server feature is available on every platform.

Public TestFlight links

A TestFlight public link invites people to install a beta; it is not a Shyni server login. External testers should use the access instructions supplied with their invitation or contact support. Do not publicly redistribute the store-review account's credentials.
