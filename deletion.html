공식 데모의 데이터

  1. 위 주소로 제목에 Shyni 계정/데이터 삭제 요청을 적어 이메일을 보내 주세요.
  2. 이용한 서버 주소와 사용자명, 삭제하려는 범위(계정 전체 또는 진도·책갈피·문의 첨부파일 등)를 알려 주세요.
  3. 계정 소유 또는 요청 권한 확인이 필요하면 비밀번호가 아닌 별도 확인 방법을 안내합니다. 대상과 처리 결과를 이메일로 안내합니다.

계정 전체 삭제 요청은 해당 계정과 관련된 진도·책갈피·저장 설정 등의 삭제를 포함합니다. 개별 데이터 삭제도 요청할 수 있습니다. 공유 심사 계정은 사용자를 구분하기 어려우므로, 요청자에게 해당하는 정보와 다른 사용자의 정보를 구분할 수 있는지 먼저 확인합니다.

운영·보안 로그 및 문의 처리 기록은 즉시 개별 삭제가 어려울 수 있으며, 해당하는 경우 남는 정보와 이유를 안내합니다. 현재 보관 방식은 개인정보처리방침에 설명되어 있습니다. 이 페이지는 이메일 요청 경로이며 즉시 자동 삭제 버튼이 아닙니다.

다른 서버 또는 기기 내 정보

직접 구축했거나 다른 사람이 운영하는 서버는 해당 관리자에게 삭제를 요청해 주세요. 앱 개발자는 독립 서버의 DB를 삭제할 권한이 없습니다. 기기 내 로그인 정보나 캐시는 앱의 로그아웃·저장공간 관리 기능으로 정리할 수 있지만, 앱 삭제만으로 서버 계정이나 이용기록이 삭제되지는 않습니다.

삭제 요청에도 비밀번호·토큰·개인키는 보내지 마세요.

Shyni account and data deletion

Official demo operator: kihyyo. Email kihyyo121@gmail.com with the subject Shyni account/data deletion request. Include the server address, username and whether you request account deletion or specific records such as progress, bookmarks or support attachments. Never send passwords or access tokens.

Shared review accounts require care to distinguish the requester's information from others'. Operational/security logs or support records may not be individually removable immediately; if relevant, retained information and the reason will be explained. See the privacy policy for retention practices. This is an email request mechanism, not an instant automatic deletion button.

Contact the relevant operator for independently hosted servers. Logging out or uninstalling a client does not delete server-side accounts or history.
